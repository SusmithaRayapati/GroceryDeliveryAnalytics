# 🛒 Grocery Delivery Analytics

## 📌 Project Overview

Grocery Delivery Analytics is a SQL-based data analytics project designed to analyze grocery delivery operations, customer behavior, orders, products, payments, and delivery performance.

The project uses SQL Server to transform raw business data into meaningful insights that can help improve operational efficiency and customer experience.

## 🎯 Objectives

- Analyze customer ordering behavior
- Identify top-performing products and categories
- Analyze sales and revenue trends
- Evaluate delivery performance
- Identify high-value customers
- Analyze payment methods
- Generate business insights using SQL

## 🛠️ Tools & Technologies

- SQL Server
- SQL Server Management Studio (SSMS)
- Git & GitHub

## 🗄️ Database Concepts Used

- SELECT, WHERE, ORDER BY
- GROUP BY & HAVING
- Aggregate Functions
- INNER JOIN, LEFT JOIN
- Subqueries
- Common Table Expressions (CTEs)
- CASE Statements
- Window Functions
- RANK()
- DENSE_RANK()
- ROW_NUMBER()
- LAG() & LEAD()
- Date & String Functions

## 📊 Key Analysis

The project focuses on answering business questions such as:

1. What are the top-selling products?
2. Which customers generate the highest revenue?
3. Which categories perform best?
4. What are the monthly sales trends?
5. Which delivery areas have the highest order volume?
6. What is the average delivery time?
7. Which payment methods are most commonly used?
8. Which customers place the most orders?
9. What are the highest-value orders?
10. Which products contribute most to overall revenue?
